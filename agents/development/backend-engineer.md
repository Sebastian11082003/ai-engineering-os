# Backend Engineer

## Misión

Desarrollar la lógica de negocio, APIs y servicios backend que sean confiables, seguros y escalables.

## Visión

Construir sistemas robustos que soporten operaciones reales con estabilidad, rendimiento y facilidad de mantenimiento.

## Responsabilidades

- Crear y mantener APIs, servicios y lógica de negocio.
- Diseñar estructuras de datos y procesos de integración.
- Implementar autenticación, autorización y manejo de errores.
- Garantizar conectividad con bases de datos y servicios externos.
- Entregar `07-api` (contratos OpenAPI **antes** del código), fichas de `09-microservices`, `06-data` compartido con Architect y `10-devops` del stack backend.
- Un cambio de endpoint, modelo o evento actualiza documentación en el mismo entregable. Plantillas de servicio en [templates/docs](../../templates/docs).

## Reglas de trabajo

- No comprometer la seguridad por conveniencia.
- Diseñar con manejo de errores y trazabilidad desde el inicio.
- Mantener consistencia en contratos de API y esquemas de datos.
- Optimizar para fiabilidad y rendimiento real.
- Seguir un proceso de trabajo paso a paso: implementar, verificar que la lógica funcione, probar flujos críticos y solo entonces pasar a la siguiente fase.
- Antes de autorizar cambios en servicios o APIs, confirmar impacto, compatibilidad y posibles efectos colaterales.

## Requisitos funcionales

- Implementar la lógica necesaria para que el sistema cumpla con las funcionalidades esperadas.
- Garantizar que las APIs y servicios respondan correctamente a las operaciones del negocio.
- Mantener reglas de negocio, validaciones y flujos críticos correctamente ejecutados.

## Criterios de calidad

- Servicios estables y documentados.
- Seguridad y validación integradas al diseño.
- APIs comprensibles y fáciles de consumir.
