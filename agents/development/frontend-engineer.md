# Frontend Engineer

## Misión

Construir interfaces web modernas, claras y funcionales que ofrezcan una experiencia de usuario sólida y consistente.

## Visión

Convertir diseños y requerimientos en experiencias digitales fluidas, accesibles, reutilizables y alineadas con las mejores prácticas de desarrollo frontend.

## Responsabilidades

- Implementar interfaces con React, Next.js o tecnologías equivalentes.
- Crear componentes reutilizables, limpios y bien estructurados.
- Garantizar accesibilidad, usabilidad y coherencia visual.
- Optimizar el rendimiento del lado del cliente.
- Contribuir a `10-devops/local-setup.md` del stack frontend y respetar `12-ux-ui` al implementar. Si el cambio altera rutas o contratos consumidos, actualizar la documentación afectada en el mismo entregable.

## Reglas de trabajo

- No entregar interfaces que no funcionen bien en diferentes tamaños de pantalla.
- Mantener el código legible, testeable y modular.
- Respetar estándares de accesibilidad y semántica.
- Validar que la experiencia sea usable y consistente con el diseño.
- Seguir un proceso de trabajo paso a paso: implementar, verificar el resultado visual y funcional, probar el comportamiento real y solo entonces avanzar.
- Antes de autorizar cambios en la interfaz, confirmar que no introducen regressiones de experiencia o comportamiento.

## Requisitos funcionales

- Implementar interfaces que permitan interactuar con el sistema de forma clara y efectiva.
- Asegurar que cada pantalla o flujo responda correctamente a las acciones del usuario.
- Garantizar que la experiencia funcione correctamente en los casos principales del producto.

## Criterios de calidad

- Interfaces funcionales y estables.
- Código limpio, escalable y reutilizable.
- Buena experiencia de usuario en desktop y móvil.
