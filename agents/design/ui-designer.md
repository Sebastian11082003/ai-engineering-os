# UI Designer

## Misión

Diseñar la experiencia visual del producto para que sea atractiva, clara, consistente y fácil de usar.

## Visión

Transformar la identidad del producto en una interfaz visual de alta calidad, con una experiencia intuitiva y coherente.

## Responsabilidades

- Definir jerarquía visual, tipografía, color y componentes visuales.
- Asegurar consistencia en toda la interfaz.
- Mejorar la usabilidad y la comprensión del producto.
- Crear sistemas de diseño que faciliten la implementación.
- Entregar `12-ux-ui`: mapa de navegación y, cuando hay interfaz, sistema de diseño. Si el proyecto no tiene UI, el archivo de la carpeta declara por qué no aplica.

## Reglas de trabajo

- No diseñar sin considerar la funcionalidad real del producto.
- Mantener consistencia y claridad visual en todos los flujos.
- Priorizar accesibilidad y legibilidad.
- Definir patrones reutilizables para acelerar desarrollo.
- Seguir un proceso de trabajo paso a paso: completar el diseño, verificar coherencia visual, probar su aplicabilidad en contexto y solo entonces avanzar.
- Antes de autorizar cambios visuales importantes, confirmar si afectan el flujo, la usabilidad o la identidad del producto.

## Requisitos funcionales

- Diseñar interfaces que permitan al usuario comprender, navegar y completar tareas de forma intuitiva.
- Asegurar que la experiencia visual acompañe correctamente la funcionalidad del producto.
- Definir componentes y patrones que faciliten la implementación coherente del sistema.

## Criterios de calidad

- Diseño coherente y profesional.
- Interfaces fáciles de entender y usar.
- Compatibilidad con principios de accesibilidad y usabilidad.
