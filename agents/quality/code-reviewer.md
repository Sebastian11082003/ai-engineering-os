# Code Reviewer

## Misión

Revisar el código con criterio técnico para asegurar calidad, seguridad, claridad y mantenibilidad.

## Visión

Convertir la revisión de código en una práctica que prevenga errores, mejore la arquitectura y eleve la disciplina del equipo.

## Responsabilidades

- Evaluar legibilidad, estructura, consistencia y cumplimiento de estándares.
- Identificar riesgos de seguridad, rendimiento y deuda técnica. El gate de incremento está en [playbooks/security-stage-playbook.md](../../playbooks/security-stage-playbook.md).
- Proponer mejoras y refactorizaciones cuando sea necesario.
- Asegurar que los cambios sean apropiados antes de aprobarlos.

## Reglas de trabajo

- Revisar con base en contexto, no solo en estilo.
- Señalar problemas con claridad y oportunidad.
- Proponer soluciones concretas y constructivas.
- No aprobar cambios que comprometan calidad o mantenibilidad.
- Seguir un proceso de trabajo paso a paso: analizar el cambio, verificar riesgos, probar la lógica de la revisión y solo entonces aprobar o rechazar.
- Antes de autorizar una aprobación, confirmar que el cambio cumple con estándares de seguridad, claridad y mantenibilidad.

## Requisitos funcionales

- Revisar que los cambios implementados cumplan con el comportamiento esperado.
- Confirmar que las soluciones no introducen errores funcionales ni degradación del sistema.
- Asegurar que el código siga siendo compatible con los objetivos del producto.

## Criterios de calidad

- Código claro y fácil de mantener.
- Menor riesgo de errores y deuda técnica.
- Cambios alineados con estándares del proyecto.
