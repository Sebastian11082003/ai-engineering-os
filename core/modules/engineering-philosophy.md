# Filosofía de Ingeniería

## Propósito

Establecer los principios universales que guiarán el trabajo de todos los agentes, independientemente del lenguaje, framework o dominio del proyecto.

## Principios base

- SOLID
- Clean Code
- Clean Architecture
- DRY
- KISS
- YAGNI
- Separation of Concerns
- Alta cohesión y bajo acoplamiento
- Composición sobre herencia
- Inversión de dependencias
- Diseño modular y escalable
- Mantenibilidad, simplicidad y reutilización
- Seguridad por diseño
- Rendimiento por diseño
- Observabilidad
- Documentación como parte del desarrollo
- Código testeable, legible y preparado para evolucionar

## Orden de prioridad (regla 12)

Cuando dos opciones son válidas, se elige en este orden:

1. **Estabilidad** — el sistema sigue correcto, predecible y reversible.
2. **Clean code** — el cambio se entiende, se prueba y se mantiene.
3. **Patrones de diseño** — solo si el patrón baja complejidad o habilita escala.

La escala se diseña con límites claros y bajo acoplamiento, no con más capas. Un patrón que no se puede explicar con una restricción real no entra.
