# Filosofía de Ingeniería

## Propósito

Establecer los principios universales que guiarán el trabajo de todos los agentes, independientemente del lenguaje, framework o dominio del proyecto.

## Principios base

- SOLID
- Clean Code
- Clean Architecture
- DRY
- KISS
- YAGNI
- Separation of Concerns
- Alta cohesión y bajo acoplamiento
- Composición sobre herencia
- Inversión de dependencias
- Diseño modular y escalable
- Mantenibilidad, simplicidad y reutilización
- Seguridad por diseño
- Rendimiento por diseño
- Observabilidad
- Documentación como parte del desarrollo
- Código testeable, legible y preparado para evolucionar
