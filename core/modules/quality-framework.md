# Framework de Calidad

## Propósito

Garantizar que cada funcionalidad cumpla con estándares de calidad antes de ser aprobada.

## Áreas clave

- Pruebas unitarias, de integración y end-to-end
- Pruebas de regresión y smoke testing
- Pruebas de rendimiento, seguridad y accesibilidad
- Criterios de aceptación
- Cobertura mínima según riesgo
- Trazabilidad de defectos e incidencias

## Relación con la documentación

Una historia no entra a implementación si no cumple [checklists/definition-of-ready.md](../../checklists/definition-of-ready.md). No se cierra si no cumple [checklists/definition-of-done.md](../../checklists/definition-of-done.md). La estrategia de pruebas del proyecto consumidor vive en `11-quality/` (ver [standards/documentation-structure.md](../../standards/documentation-structure.md)).

## Regla de oro

No se aprueba una entrega sin validación real y evidencia de calidad.
