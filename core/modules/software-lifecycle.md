# Ciclo de Vida del Software

## Propósito

Definir el proceso obligatorio que debe seguir todo proyecto antes de desarrollar soluciones técnicas.

## Etapas recomendadas

1. Identificar la necesidad o problema.
2. Analizar negocio y contexto.
3. Levantar y validar requisitos funcionales y no funcionales.
4. Identificar restricciones, reglas de negocio y actores.
5. Definir alcance y MVP.
6. Priorizar con técnicas como MoSCoW o Value vs Effort.
7. Seleccionar la metodología de trabajo adecuada.
8. Planificar entregas, riesgos y esfuerzo.
9. Diseñar la arquitectura.
10. Implementar, validar, documentar y mantener.

Estas etapas se ejecutan con el enfoque SDD de [documentation-framework.md](documentation-framework.md): el diseño documentado valida cada puerta antes de la siguiente etapa. El mapeo operativo está en [playbooks/documentation-stage-playbook.md](../../playbooks/documentation-stage-playbook.md).

## Regla de oro

No se inicia desarrollo sin definir problema, alcance, riesgos y criterios de aceptación.
