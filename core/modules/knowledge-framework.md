# Framework de Conocimiento

## Propósito

Asegurar que el proyecto preserve aprendizaje, contexto y memoria operativa a lo largo del tiempo.

## Áreas clave

- Documentación viva del sistema
- Decisiones arquitectónicas y trade-offs
- Conocimiento del negocio, usuarios y dominio
- Registros de incidentes y aprendizajes
- Transferencia de conocimiento entre agentes y equipos
- Continuidad operativa y onboarding

## Relación con la documentación

El glosario, el mapa de dominio, los ADRs, los incidentes y el archivo histórico (`99-archive`) son la memoria operativa del proyecto. Si el código y el documento divergen, el conocimiento está corrupto (ver [documentation-framework.md](documentation-framework.md)).

## Regla de oro

El conocimiento debe ser compartido, versionado y reutilizable.
