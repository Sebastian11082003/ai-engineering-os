# Playbooks

Guías de ejecución repetibles. Los principios viven en `core/`; los playbooks dicen en qué orden se aplican.

- [documentation-stage-playbook.md](documentation-stage-playbook.md) — secuencia SDD para producir y validar la documentación de un proyecto **nuevo**.
- [existing-project-adoption-playbook.md](existing-project-adoption-playbook.md) — adoptar SDD y living-docs en un repo que ya tiene código y docs, sin reescribir.
- [quality-stage-playbook.md](quality-stage-playbook.md) — cómo el Orchestrator cierra calidad en un incremento (DoR → evidencia → DoD).
