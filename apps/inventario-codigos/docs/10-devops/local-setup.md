# Setup local

1. Node.js 20 o superior.
2. `cd apps/inventario-codigos`
3. `npm ci`
4. `npm test`
5. `npm run dev` y abrir `http://localhost:5173`

Eso alcanza para la ficha, las categorías, la persistencia y el Excel. La cámara del teléfono no se prueba contra la IP de la LAN: hace falta el HTTPS de [environments.md](environments.md).
