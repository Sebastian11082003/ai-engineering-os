# Manual de uso

1. Abre la dirección `https://` en el teléfono.
2. Pulsa el botón amarillo **Escanear con la cámara**.
3. Permite la cámara cuando el navegador lo pida. Se usa la de atrás.
4. Apunta al código hasta que aparezca. Pulsa **Usar este código**.
5. Escribe el nombre, elige categoría, cantidad y unidad. El precio puede quedar vacío.
6. Guarda. El producto queda en el estante aunque cierres la pestaña.
7. Corrige con − y + o abriendo el tiquete.
8. Pulsa **Exportar Excel** y lleva ese archivo al punto de venta.

Si la cámara no puede usarse, **Escribir código** cumple el mismo camino a partir del paso 5.

Categorías: desde el estante, **Categorías**. Las cuatro iniciales se pueden renombrar.

El archivo no se envía a ningún servidor. Quien tenga el teléfono puede ver la lista.
