# Overview

Sebastian Osorio necesita registrar productos de una bodega o mostrador escaneando el código con el teléfono, clasificarlos y llevarse un Excel que un punto de venta pueda importar.

La aplicación corre en el navegador del teléfono. La cámara trasera es el camino principal. Los datos no salen del aparato hasta que la persona descarga el Excel.

Origen: pedido del stakeholder en este repositorio, sin reescribir el AI Engineering OS.
