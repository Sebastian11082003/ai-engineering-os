# Contributing

Gracias por contribuir a este proyecto.

## Guidelines

- Mantén los cambios acotados a un objetivo.
- Si cambia comportamiento, backend, frontend, base de datos o infraestructura, actualiza la documentación **en el mismo PR**. El job **Documentación viva** lo exige ([standards/living-docs-ci.md](standards/living-docs-ci.md)).
- Prefiere claridad sobre ingenio.
- No marques Done una historia si el CI de documentación está en rojo.
