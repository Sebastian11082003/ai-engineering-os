# AGENTS

Este repositorio funciona como un sistema operativo de ingeniería asistida por IA.

## Propósito

- Centralizar la visión, los principios, los agentes y los flujos de trabajo del proyecto.
- Servir como base reutilizable para futuros proyectos y equipos.

## Estructura principal

- [README.md](README.md): visión general del sistema.
- [core/AGENTS.md](core/AGENTS.md): guía operativa central.
- [agents](agents): definiciones de agentes especializados.
- [teams](teams): modelos de equipos por contexto.

## Reglas de trabajo

- Comprender el contexto antes de actuar.
- Definir alcance y requisitos antes de implementar.
- Documentar decisiones, riesgos y resultados.
- Ejecutar documentación con SDD: [standards/documentation-structure.md](standards/documentation-structure.md) y [playbooks/documentation-stage-playbook.md](playbooks/documentation-stage-playbook.md).
- Validar calidad, seguridad y trazabilidad antes de cerrar una entrega.
